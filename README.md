# Minhas anotações
Este repositório é dedicado a armazenar minhas anotações sobre software design, arquitetura de software, padrões de projeto e outros tópicos relacionados. Ele serve como um recurso pessoal para referência futura e compartilhamento de conhecimento com outros desenvolvedores.

## Estrutura do Repositório
- `design-patterns/`: Contém anotações sobre padrões de projeto, incluindo exemplos de código e explicações detalhadas.
- `design-principles/`: Inclui anotações sobre princípios de design, como SOLID, DRY, KISS, entre outros.
- `software-architecture/`: Anotações sobre arquitetura de software, incluindo estilos arquiteturais.
- `best-practices/`: Dicas e melhores práticas para desenvolvimento de software, incluindo testes, documentação e gerenciamento de projetos.
- `resources/`: Links para artigos, livros e vídeos relacionados aos tópicos abordados nas anotações.
- `README.md`: Este arquivo, que fornece uma visão geral do repositório e sua estrutura.
